## About

I study veterinary medicine and spend my free time building networking tools. My main work is Tomato, a VPN autoscript for Linux servers, plus a tunnel client that brings the same protocols to OpenWrt routers.

I care about things that are easy to install, easy to read on a phone screen, and keep running without babysitting.
